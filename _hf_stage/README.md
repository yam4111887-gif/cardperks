# 卡優惠 CardPerks

記下你的卡 → 搜尋商家 → 立即比較回饋金額、綁定支付與登錄條件。
優惠資料每日自動更新自各發卡銀行官網，每筆附原始來源佐證與查核日期。

- 地圖模式：附近商家有哪些卡有優惠
- Pro：優惠到期提醒、帳單健檢（算出你刷錯卡少賺多少）
- 資料透明：每筆優惠可點開「原始資料來源」自行驗證
